## 🚀 **Quick Deploy Steps:**

### 1. Install Vercel CLI
```bash
npm i -g vercel
```

### 2. Login to Vercel
```bash
vercel login
```

### 3. Deploy (from root directory)
```bash
# Windows
deploy.bat

# Linux/Mac
chmod +x deploy.sh
./deploy.sh
```

### 4. Set Environment Variables in Vercel Dashboard
```
VITE_API_URL=https://your-app.vercel.app/api
NODE_ENV=production
```
