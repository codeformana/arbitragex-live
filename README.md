## 🚀 **Quick Start**

### **Prerequisites**
- Node.js 18+ 
- npm or yarn
- Git

### **Installation**
```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/arbitragex-live.git
cd arbitragex-live

# Install frontend dependencies
cd arbitragex-platform/frontend
npm install

# Install backend dependencies  
cd ../backend
npm install
```

### **Development**
```bash
# Start backend (Terminal 1)
cd arbitragex-platform/backend
npm start

# Start frontend (Terminal 2)
cd arbitragex-platform/frontend  
npm run dev
```

### **Production Build**
```bash
# Build frontend
cd arbitragex-platform/frontend
npm run build

# Start production server
cd ../backend
NODE_ENV=production npm start
```
